# Оружейная в браузере

Четыре самодостаточных HTML-файла (одно оружие — один файл) в `dist/`:

| Файл | Оружие |
|---|---|
| `dist/akm.html` | АКМ, 7,62×39 |
| `dist/ak74_modular.html` | АК-74М, 5,45×39 |
| `dist/m416.html` | HK416 A5 (M416), 5,56×45 |
| `dist/scar-h.html` | FN SCAR-H Mk 17, 7,62×51 |

Файл открывается двойным кликом — нужен только интернет для загрузки three.js с unpkg.

## Что внутри

- Процедурные модели по реальным размерам (мм): штампованная коробка АК с окном выброса,
  монолит SCAR, верх/низ AR с окном, затворной рамой, крышкой окна и т. д.
- Единое меню модификации: цевья, крышки, кронштейны, прицелы (коллиматоры Aimpoint T-2 /
  CompM4s, Trijicon MRO, RMR на райзере, Holosun HS510C, ПК-120, ОКП-7Д на «ласточкин хвост»;
  голографические EOTech EXPS3 / XPS2; ACOG TA31RMR — через верхний RMR тоже можно целиться, V), 1–6×, ПСО-1, «Кобра», увеличитель 3×, ПНВ AN/PVS-14 за коллиматором), боковой
  RMR на 45° кронштейне (при прицеливании оружие заваливается), мушки/целики, ДТК,
  линейные компенсаторы и глушители (у HK416 — свои: B&T Rotex-V и KAC NT4), фонари, ЛЦУ, блок DBAL-PL (фонарь + лазер), рукоятки,
  сошки, магазины, приклады, рукояти. Положение модуля на планке меняется ◀ ▶; если
  увеличителю/ПНВ не хватает места, основной прицел сдвигается вперёд автоматически.
- Модули ставятся только туда, где есть подходящее крепление (планка, резьба, «ласточкин
  хвост»), башмак строится от верхней плоскости планки — ничего не висит в воздухе.
  Несовместимое не показывается, занятое — с причиной.
- Прицеливание через выбранный прицел (сетка проецируется «в бесконечность» сквозь линзу),
  увеличенные прицелы с кратностью, стрельбище с мишенями.
- Процедурный звук: калибр, механика, эхо; глушитель, ДТК, линейный компенсатор и
  пламегаситель звучат по-разному. Перезарядка и механика (`src/engine/foley.js`) — физическая
  модель удара: импульс контакта (сталь/полимер/ладонь) возбуждает плотный банк демпфированных
  резонаторов корпуса, трение — поток микрозацепов, плюс шевеление патронов в магазине и «масса»
  оружия. Чистых синусоид нет — поэтому нет «колокольчиков».
- Эффекты: дульное пламя из скрещённых плоскостей вдоль оси (сбоку — язык пламени, с торца —
  «звезда»; у пламегасителя — лепестки, у тормоза — боковые струи) с подсветкой сцены на один
  кадр; дым бездымного пороха — прозрачная серо-голубая дымка из фрактального шума, искры, дымок из окна и от нагретого ствола,
  гильзы с кувырком и отскоками. Частицы и гильзы рисуются инстансингом.
- Производительность: кадр рисуется только при изменениях, тени пересчитываются только когда
  двигаются отбрасывающие их объекты, разрешение во время движения подстраивается под FPS
  (неподвижная картинка — всегда в полном качестве).

Управление — кнопка «?» в правом нижнем углу (или клавиша H).

## Разработка

```bash
npm install
npm run build        # собрать dist/*.html
npm run watch        # пересборка при изменениях
node build.mjs --only=akm,scar
```

Исходники: `src/engine/` — движок (геометрия, материалы, крепления, звук, эффекты, интерфейс),
`src/engine/lib/` — общие модули, `src/weapons/` — модели оружия. Контракт модели описан в
`docs/WEAPON_API.md`. Отладочные URL-параметры: `?view=left&zoom=2&cfg={"optic":"exps3"}&ui=0`.
